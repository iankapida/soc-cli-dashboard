# SOC CLI Dashboard

A Python-based enterprise SOC command-line tool for threat detection, auditing, and triage.

## 🚀 Core Capabilities
It features a **9-phase security automation pipeline**:
1. **Master Orchestrator** (`master_soc.py`)
2. **Port Scanner** (`port_scanner.py`)
3. **File Integrity Monitor** (`fim_monitor.py`)
4. **Cloud Token Auditor** (`cloud_token_audit.py`)
5. **IAM Auditor** (`iam_auditor.py`)
6. **DFIR Parser** (`dfir_parser.py`)
7. **Network & Endpoint Monitors** (`endpoint_monitor.py`, `network_flow.py`)
8. **Anomaly Detector** (`anomaly_detector.py`)
9. **Threat Intelligence IP Checker** (`threat_intel_checker.py`)
